# 📚 Library Project

A responsive web application that allows users to manage a personal book collection. Users can add books, remove books, and update their reading status through an intuitive interface. The project demonstrates object-oriented programming concepts, DOM manipulation, and dynamic rendering using vanilla JavaScript.

## 🚀 Live Demo

🔗 https://nzube606.github.io/library-project/

---

## ✨ Features

- Add new books to the library
- Remove books from the collection
- Toggle reading status (Read / Unread)
- Responsive user interface
- Dynamic rendering without page refresh
- Unique IDs assigned to every book

---

## 🛠️ Built With

- CSS3

- Object-Oriented Programming

## 📖 What I Learned

This project was built as part of The Odin Project to practice object-oriented JavaScript. The goal wasn't just to build a book tracker, but to learn how to model real-world data with classes and keep the UI synchronized with application state.
It helped me strengthen my understanding of:

- JavaScript Classes and Objects
- DOM manipulation
- Event handling
- Dynamic rendering
- Managing application state
- Writing reusable functions
- Generating unique identifiers using `crypto.randomUUID()`

---

## 🚧 Challenges

One of the biggest challenges was ensuring that changes made to the library (adding, deleting, or updating books) were immediately reflected in the user interface. I solved this by creating a centralized rendering function that redraws the library whenever the data changes.
